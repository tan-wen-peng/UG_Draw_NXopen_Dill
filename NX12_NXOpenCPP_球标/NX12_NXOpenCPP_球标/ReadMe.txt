 球标标注 step1（balloon_step1.dll）
------------------------------------------------------------
 功能：手动逐点点选，顺序编号（不弹选择对话框）。
   运行后在 NX 图形窗口直接点选部件上的位置，每点一处
   创建一个圆形球标（ID 符号），编号从 1 开始依次 +1，
   直到点取消结束。
   球标规格：类型=圆、大小=40、文字字体=仿宋（正立不斜体）、
   文字大小=20、箭头长度=8，点选位置 = 指引线终止位置。

 使用方法：
   1. NX12 打开图纸，进入制图环境（激活要标注的图纸页）
   2. 文件 -> 执行 -> NX Open（快捷键 Ctrl+U），
      选择 bin\Release\balloon_step1.dll
   3. 按提示在部件上逐个点选引线终止位置；点取消结束
   4. 列表窗口输出创建统计；不满意 Ctrl+Z 一次撤销全部

 配置项（源码顶部常量）：
   START_NUMBER  起始编号，默认 1（之后依次 +1）
   WITH_LEADER   true=球标带指引线，false=只有球标
   BALLOON_SIZE  球标圆的直径，默认 40
   TEXT_HEIGHT   球标内数字的字高，默认 20
   ARROW_LENGTH  引线箭头长度，默认 8
   TEXT_FONT     文字字体名，默认 FANGSONG（找不到时自动尝试
                 FangSong/仿宋/仿宋_GB2312）
   OFFSET_X/Y    球标中心相对选择点的偏移（图纸坐标），默认 25/25

 说明：
   - 点选位置即指引线终止位置；球标中心 = 点选位置 + OFFSET
   - 点在投影视图内部时，选点坐标自动从模型坐标映射到图纸坐标
   - 球标大小/字体在创建后由程序统一设置，不依赖制图首选项
